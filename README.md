# COBBY MOTORS

COBBY MOTORS is a vehicle assistance platform connecting drivers with mechanics.

## Apps

- Driver App
- Mechanic App
- Admin Dashboard

## Driver App

Drivers can:
- Request a mechanic
- Describe vehicle problems
- Get basic vehicle diagnosis
- Track mechanic requests
- View service history
- Manage their profile

## Mechanic App

Mechanics can:
- Receive service requests
- Accept jobs
- View driver location
- Diagnose vehicles
- Send repair prices
- Complete jobs
- View earnings
- Manage their profile

## Payment

The prototype uses an 85/15 payment split:

- 85% — Mechanic
- 15% — COBBY MOTORS platform

## Project Status

Frontend prototype under development.

Production features such as authentication, GPS tracking, real payments, notifications and database integration will be added later.
